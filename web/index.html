    The model

    Kd = (RT − B)(LT − B) / B

    The solver uses a scaled, cancellation-resistant solution and independently evaluates free ligand. Site concentration comes from accessible sites, cell number, and incubation volume. Bounds use all four input corners.

    The design rule

    Rcap = εLT + εKd / (1 − ε)

    The lowest positive dose sets the binding-capacity limit. Recommended volume is rounded up and cells down, then rechecked through the same model.
